# onyx-hackathon-build: background

Updated 2026-11-04 (sixty-sixth wrap, Opus: Task 46 merged, PR #16; Task 48 built except gap 2, draft PR #17).

## What this is

Mizan, team Onyx's entry to the ITU AI for Good Lab Hackathon UAE 2026 (telecom T1). Agents propose JSON actions; plain-code gates decide from clauses of binding UAE text; every step goes to a hash-chained log. Orders: `docs/work-orders/` in date order, each with its report-back in `docs/report-back/` (chain to Task 16: archive, 2026-10-22). main holds Tasks 36 to 45 (PR #14, merge `8b5a569`, CI passed); `task-47` holds Task 47 so far, no PR; each task since 29 is one PR and one tag. hq's report-back rulings on Tasks 14 and 16 are filed at the end of those orders. Thinking and business facts: `D:\Projects\hq\uni\ai-for-good-hackathon\`. Submission 2026-11-09.

## Stack and how it runs

Python 3.12 (uv), ChromaDB 1.5.9 (default embedding all-MiniLM-L6-v2, 79 MB, downloaded once), pytest, jsonschema, pypdf, matplotlib 3.11.2 (dev, figures only), python-docx 1.2.0 (dev, report only; brings lxml). CLI: `python -m onyx kb fetch|verify|chunk|ingest|export`, `python -m onyx check-data`, `python -m onyx verify-log <file>`, `python -m onyx run S1..S5 [--lang ar] [--ungoverned] [--inject TEXT]` (scripted, offline), `python -m onyx record --source scripted|live [--root DIR] [--modes governed ungoverned] [--runs N] [--max-usd 5] [--skip-existing]`, `python -m onyx bakeoff [--out eval]` (v1 and v2 tables from `bakeoff.VERSIONS`), `python -m onyx selftest` (S1 offline, no key, headline figures), `python -m onyx replay <log>` (prints the hand-over quotes EN and AR), `python -m onyx replay-page [--html]`, `python -m onyx whatif <log> [--rule gap-1|gap-4] [--out DIR]`, `python -m onyx why <log> --step <n> [--lang ar]` (Task 36), `python -m onyx model-down <log> --at <step> [--out DIR]` (fault injection: the model call at one step fails; the coordinator logs `model_unavailable` and the gate decides a plain-code `escalate_to_human`), `python -m onyx gaps`, `python -m onyx eval --runs <root> --out <dir>`. Live model: `.env` at the repo root (gitignored) with ONYX_MODEL_BASE_URL, ONYX_MODEL, ONYX_MODEL_API_KEY; names in `.env.example`. The process environment overrides `.env` per name, so `ONYX_MODEL=claude-sonnet-5-5 uv run python -m onyx record ...` picks a model without editing `.env`. `ONYX_SOURCE_DIR=D:\Projects\hq\uni\ai-for-good-hackathon` lets `kb fetch` fall back to the hq copies and `kb chunk` read the hq text extractions (maintainer only); the CPR Arabic it reads from the PDF with pypdf, because the hq .txt files (made with PyMuPDF) reverse the lam-alef. Remote: github.com/SHRA1M/onyx-hackathon-build, private, branches main and backup/main, CI `reproduce.yml` on push (uv sync, kb verify, check-data, pytest, selftest, verify-log on every committed log, replay S1 to S5, eval live and scripted, gaps, replay-page, replay-page --html, both figure scripts, `git diff --exit-code`; no kb fetch, no secret; badge in README). Not hosted; no push deploys.

## Traps

- Never pipe a long build through `tail`: it hid the errors of a 47-minute Task 47 build. Give a long download a `timeout` and check it against the order's limit. Model repos hold hundreds of result files: name what to fetch (`allow_patterns`). This PC's download is about 1.4 MB/s; `multilingual-e5-small` took 12 min 45 s.
- Any change to `kb/chunks`, a scenario's text or a mandate's documents fails `eval` until `kb ingest` and `eval` run with both indexes on this PC (`StaleMeasurement`). `kb_main` holds 161 chunks since 2026-11-04.
- Every Y.3172 chunk carries page 1 (chunker quirk); a gap row gives its own `page`. `kb/sources/global/` is gitignored, so the verbatim global-quote test skips in CI.

- Recorded spend USD 21.85 against the USD 30 stop; the API organisation holds USD 100 promotional credit (granted 2026-10-27, expires 2026-11-25). `record`'s estimate counts both languages even when one is skipped.
- Arabic printed to a redirected file from Windows Python comes out in cp1256: run `python -X utf8` (`-I` ignores `PYTHONIOENCODING`). Git Bash has no `iconv`.
- The ChromaDB index (`data/chromadb`, gitignored) goes stale after any `kb chunk`: live retrieval then returns clause ids not in `kb/chunks` and the run dies (KeyError). Run `python -m onyx kb ingest` after every `kb chunk`.
