## Stack and how it runs

Python 3.12 (uv), ChromaDB 1.5.9 (default embedding all-MiniLM-L6-v2, 79 MB, downloaded once), pytest, jsonschema, pypdf. CLI: `python -m onyx kb fetch|verify|chunk|ingest|export`, `python -m onyx check-data`, `python -m onyx verify-log <file>`, `python -m onyx run S1..S5 [--lang ar] [--ungoverned] [--inject TEXT]` (scripted, offline), `python -m onyx record --source scripted|live [--root DIR] [--modes governed ungoverned] [--runs N] [--max-usd 5] [--skip-existing]`, `python -m onyx bakeoff [--out eval]` (v1 and v2 tables from `bakeoff.VERSIONS`), `python -m onyx selftest` (S1 offline, no key, headline figures), `python -m onyx replay <log>` (prints the hand-over quotes EN and AR), `python -m onyx replay-page`, `python -m onyx gaps`, `python -m onyx eval --runs <root> --out <dir>`. Live model: `.env` at the repo root (gitignored) with ONYX_MODEL_BASE_URL, ONYX_MODEL, ONYX_MODEL_API_KEY; names in `.env.example`. The process environment overrides `.env` per name, so `ONYX_MODEL=claude-sonnet-5-5 uv run python -m onyx record ...` picks a model without editing `.env`. `ONYX_SOURCE_DIR=D:\Projects\hq\uni\ai-for-good-hackathon` lets `kb fetch` fall back to the hq copies and `kb chunk` read the hq text extractions (maintainer only); the CPR Arabic it reads from the PDF with pypdf, because the hq .txt files (made with PyMuPDF) reverse the lam-alef. Remote: github.com/SHRA1M/onyx-hackathon-build, private, branches main and backup/main, CI `reproduce.yml` on push (uv sync, kb verify, check-data, pytest, selftest, verify-log on 196 logs, replay S1 to S5, eval live and scripted, gaps, replay-page, `git diff --exit-code`; no kb fetch, no secret; badge in README). Not hosted; no push deploys.

## Traps

- Every Y.3172 chunk carries page 1 (chunker quirk); a gap row gives its own `page`. `kb/sources/global/` is gitignored, so the verbatim global-quote test skips in CI.
- Adding cited clauses: `kb chunk` rewrites kb/chunks; keep HEAD's lines and add only the new clause lines (Task 9 did this with a merge script), then `kb ingest`.

- Prompt v4 care prompts are about 7x v3. The spend guard (medians of mostly older calls) says USD 0.32 per scenario; C4 actual was USD 0.82 to 1.31 per scenario (4 runs). Estimate from the C4 per-run costs in `eval/results.json` (`c4.runs`) and pass `--max-usd` as the cap left.
