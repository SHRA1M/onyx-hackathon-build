## Question 1: gap 2 (item 2), two stop conditions met

**The contradiction.** I read CPR 4.15 to 4.23 whole in `kb/sources/tdra-cpr-v2-en.pdf` (pages 16 to 19), and 4.7 to
4.14. "A conversational agent fits none of them" meets these clauses:

| Clause | Text | Against "fits none" |
|---|---|---|
| 4.17 | "purchased via a telephone call to/from a Licensee's call centre" | A voice agent on the operator's line is a telephone call; 4.17.3's recording can be made |
| 4.19 | "interactive electronic communications (SMS or USSD)"; agreement "by a separate step" | An agent over SMS fits; the order's row does not list 4.19 |
| 4.21, 4.22 | Licensee App is "any bespoke application ... to interact with that Licensee"; "made via a Licensee App" | A chat agent in the app is a purchase via the app. 4.22.3 applies only "where Consumers are offered on-screen, yes/no options", so no screen means the clause does not bite, not that the medium does not fit |
| 4.23 | "made online, or via a device ... or any other such device ... not specifically covered elsewhere" | The catch-all: a web chat is online, so 4.23.2's 2FA applies |
| 4.10 | "In all digital applications ... 2FA" unless "expressly specified otherwise" | Reaches any digital agent; the ordered row drops it |

The repo already says the same in gap 2's `searched` lines, which the order keeps: 4.17 "A voice agent reads naturally as
this."; 4.22 "A chat agent in the app reads as this or as 4.10." The ordered row would sit beside them in `docs/gaps.md`.
Its own next clause, "the same agent meets a different standard depending on where the operator embeds it", also assumes
the agent fits each medium.

What holds up: the same agent meets a different standard by where it is embedded; no medium names an AI channel; whether a
recorded spoken "yes" meets PDPL 6(1)(b) is unsaid. Whether "a telephone call to/from a Licensee's call centre" reaches a
call with no human in it is an open reading, and that is a legal judgement I am not making.
